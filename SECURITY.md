# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **ClashView Sync**, please do **not** open a public issue. Instead, please report it responsibly by contacting the maintainer directly:

- **Author:** Hazem Sakr
- **Contact:** [Hazem Sakr on LinkedIn](https://www.linkedin.com/in/hazem-sakr/)

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof of concept.
- Potential impact on Autodesk Revit models or workshared central environments.

We take model safety and database non-destructiveness seriously and will respond promptly to investigate and patch any identified issues.
